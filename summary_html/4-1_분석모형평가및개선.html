    1. 분석모형 평가

    평가 지표

    분류모델 평가지표
    • (1) 혼동행렬(오분류표)

    예측과 실제가 같으면 TRUE, 예측이 TRUE면 POSITIVE

    • (2) 평가지표
    • 1) 재현율(Recall)은 민감도(Sensitivity), TP Rate, Hit Rate라고도 함
    • 2) F-1 Score는 Precision과 Recall의 조화평균
    • 3) Precision과 Recall은 Trade-Off 관계
    • 4) F-β Score

    − β > 1 : 재현율(Recall)에 큰 비중
    − β < 1 : 정밀도(Precision)에 큰 비중
    − β = 1 : F-1 Score와 동일

    • (3) ROC 커브
    • 가로축을 1-특이도(FPR), 세로축을 민감도(TPR)로 두어 시각화한 그래프
    • 그래프 면적(AUC)은 0.5~1사이이며, 1에 가까울수록 모델의 성능이 좋다고 평가
    • (4) 이익도표(Lift chart)
    • 임의로 나눈 각 등급별로 반응검출율, 반응률, 리프트 등의 정보를 산출하여 나타내는 도표
    • 향상도 곡선 : 이익도표를 시각화한 곡선

    분석모형 진단

    과대적합과 과소적합
    • (1) 과대적합(Overfitting) : 높은 분산, 낮은 편향
    • (2) 과소적합(Underfitting) : 낮은 분산, 높은 편향

    분산과 편향의 Trade-Off 확인으로 최적의 모델 선정

    교차 검증

    교차 검증
    • (1) 홀드아웃 : 전체 데이터를 학습용과 검증용으로 한 번만 나누어 사용
    • (2) K-fold 교차검증 : 데이터를 k개의 집단으로 구분하여 k-1개 학습, 나머지 1개로 검증
    • (3) LOOCV : 1개의 데이터로만 검증 나머지로 학습, 신뢰도가 높지만 연산량이 많음
    • (4) 부트스트래핑 : 복원추출을 활용하여 데이터 셋을 생성, 데이터 부족, 불균형 문제 해소

    적합도 검정

    적합도 검정
    • (1) Q-Q plot : 데이터의 정규성을 분포의 분위수를 활용하여 시각적으로 파악
    • 정규성 존재한다면, 점들이 대각선(45도) 위에 분포
    • (2) 카이제곱 검정 : 변수를 범주로 묶어 적합성에 대한 검정
    • (3) 샤피로 윌크 검정 : 데이터의 표준정규점수와 선형상관관계를 측정하여 검정
    • (4) 콜모고로프-스미르노프 검정 : 누적 분포함수를 비교하여 연속형 데이터의 검정

    모수 유의성 검정

    모수 검정의 전제 조건
    • (1) 정규성 : Shapiro-Wilk 검정, Q-Q Plot
    • (2) 등분산성 : Levene 검정, F-검정
    • (3) 독립성 : 더빈-왓슨 검정
    모수 유의성 검정
    • (1) Z-검정 : 표본이 모집단에 속하는 검정
    • (2) t-검정 : 한 집단의 평균 또는 두 집단의 평균 차이 비교 검정 (단일표본, 독립표본, 대응표본)
    • (3) F-검정 : 두 집단의 분산의 동일성 검정 시 사용
    • (4) ANOVA 검정 : 셋 이상의 집단에 대한 평균 검정
    원문 60쪽

    두 학교의 학생들의 수학 점수에 대한 t 검정

    • 1) 귀무가설/대립가설 설정
    • 귀무가설 : 두 학교의 평균 점수는 동일하다.
    • 대립가설 : 두 학교의 평균 성적은 동일하지 않다.
    • 2) 검정유형 확인
    • 대립가설의 값이 같지 않다 → 양측검정
    • 서로 다른 모집단에 대한 평균비교 검정 → 독립표본 t-검정
    • 3) 귀무가설 기각 혹은 채택
    • p-value : 0.5515 > 유의수준(α) : 0.05 → 귀무가설 채택
    • 4) 결론
    • 두 학교의 평균 점수 차이는 통계적으로 유의하지 않다.

    독립표본 t-검정은 두 집단의 분산이 같다는 가정(등분산 가정)이 전제가 되며, 등분산을 가정하 지 않는 경우 Welch의 t-검정을 사용

    1. 1. 분류모델 평가지표에 대한 설명으로 옳지 않은 것은?

      정답 ③ — Precision과 Recall은 Trade-Off 관계다.

    2. 2. ROC 커브에 대한 설명으로 옳은 것은?

      정답 ③ — ROC 커브는 가로축 1-특이도(FPR), 세로축 민감도(TPR)이며 AUC는 0.5~1 사이로 1에 가까울수록 성능이 좋다.

    3. 3. 군집분석의 평가지표에 대한 설명으로 옳지 않은 것은?

      정답 ④ — 같은 군집 간에는 응집도가 높고, 다른 군집 간에는 응집도가 낮아야 좋은 모델이다.

    4. 4. 과대적합과 과소적합에 대한 설명으로 옳은 것은?

      정답 ③ — 과대적합은 높은 분산·낮은 편향, 과소적합은 낮은 분산·높은 편향이다.

    5. 5. 교차 검증 방법에 대한 설명으로 옳지 않은 것은?

      정답 ③ — LOOCV는 1개의 데이터로만 검증하고 나머지로 학습하며, 신뢰도가 높지만 연산량이 많다.

    과대적합 방지방안

    • (2) 하이퍼파라미터 : 최적의 파라미터 도출이 목적이며, 사용자가 수동으로 설정

    하이퍼파라미터 튜닝
    • (1) Manual Search : 경험 또는 감으로 설정
    • (2) Grid Search : 모든 조합을 탐색
    • (3) Random Search : 임의로 탐색
    • (4) Bayesian Optimization : 모델링을 통한 최적의 조합 발견
    경사하강법 옵티마이저
    • 옵티마이저를 통하여 경사하강법의 학습속도 및 지역 극솟값 수렴 문제 해결 가능
    • 1) Momentum: 이전 기울기를 일정 비율로 반영해 진동을 완화하고 수렴을 가속화
    • 2) Adagrad: 누적 기울기 정보를 활용해 학습률을 자동 조정, 시간이 지날수록 학습률 감소
    • 3) RMSProp: 지수이동평균을 이용해 학습률을 조절, 급격한 학습률 감소를 방지
    • 4) Adam: Momentum과 RMSProp의 장점을 결합

    1. 1. 과대적합 방지방안의 관점별 연결이 옳지 않은 것은?

      정답 ④ — 차원축소는 데이터 관점(피처 선택 및 차원축소)에 속한다. 학습 및 검증 프로세스 관점은 교차검증, 조기종료다.

    2. 2. 파라미터와 하이퍼파라미터에 대한 설명으로 옳은 것은?

      정답 ③ — 파라미터는 최적화된 모델 구현이 목적이며 수동 설정이 불가하고, 하이퍼파라미터는 최적의 파라미터 도출이 목적이며 사용자가 수동으로 설정한다.

    3. 3. 경사하강법에서 학습률(α)에 대한 설명으로 옳은 것은?

      정답 ③ — α가 너무 클 때는 발산하고, 너무 작을 때는 수렴하는 데 시간이 오래 걸린다.

    4. 4. Batch Size, Epoch, Iteration에 대한 설명으로 옳지 않은 것은?

      정답 ④ — Epoch는 모든 데이터셋을 학습하는 횟수이며, 하나의 소그룹에 속하는 데이터 수는 Batch Size다.

    5. 5. 경사하강법 옵티마이저에 대한 설명으로 옳은 것은?

      정답 ③ — Momentum은 이전 기울기 반영으로 진동 완화, Adagrad는 누적 기울기로 학습률 자동 조정, RMSProp은 지수이동평균으로 급격한 학습률 감소 방지, Adam은 Momentum과 RMSProp의 결합이다.
