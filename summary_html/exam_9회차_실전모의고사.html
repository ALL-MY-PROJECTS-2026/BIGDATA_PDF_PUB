‘인자기’

빅데이터의 가치

빅데이터 가치 산정이 어려운 이유

  • (1) 특정 데이터를 언제, 어디서, 누가 활용할지 알 수 없음
  • (2) 기존에 가치 없는 데이터도 새로운 분석기법으로 가치를 창조

빅데이터가 만들어내는 변화

  • (1) 표본조사 → 전수조사
  • (2) 사전처리 → 사후처리
  • (3) 질 → 양
  • (4) 인과관계 → 상관관계

‘전후양상’

데이터 산업의 이해

데이터 사이언스

  • 데이터와 관련된 모든 분야의 전문지식을 종합한 학문
  • 정형/비정형 데이터를 막론하고 데이터를 분석 (총체적 접근법)

데이터 사이언스 핵심 구성요소

  • (1) 분석(Analytics) : 수학, 확률, 머신러닝, 분석학 등
  • (2) IT : 프로그래밍, 데이터 엔지니어링, 컴퓨팅 등
  • (3) 비즈니스 분석 : 커뮤니케이션, 스토리텔링, 시각화 등

데이터 사이언티스트의 필요역량

  • (1) Hard Skill : 이론적 지식(수학, 통계학, 가설검정 등), 분석 기술에 대한 숙련
  • (2) Soft Skill : 통찰력(창의적 사고, 호기심, 비판), 설득력(스토리텔링, 시각화), 협력(커뮤니케이션)

가트너가 제시한 역량 : 데이터 관리, 분석 모델링, 비즈니스 분석, 소프트 스킬

하드스킬은 이과적, 소프트 스킬은 문과적인 느낌

2.빅데이터의 이해쉬움부정형
빅데이터의 3V 와 상황의 연결로 옳지 않은 것은?
정답 ② — 데이터가 얼마나 빠르게 만들어지고 처리되어야 하는가가 속도(Velocity)다. "초당" 이라는 말은 속도를 가리키며, 종류가 여럿인 것이 다양성, 쌓인 총량이 큰 것이 규모다.근거 · 요약노트 5쪽
관련 요약 개념 · 요약노트 원문 5쪽

데이터베이스 시스템

  • (1) DBMS : DB를 관리, 접근 환경 제공하는 소프트웨어
  • (2) 데이터베이스 스키마 : DB의 구조와 제약조건에 관한 전반적 명세
  • 메타데이터 : 데이터를 설명하는 데이터, 데이터 구조를 설명하고 검색하는데 활용
  • 데이터 사전 : 메타데이터와 데이터 구조 정보를 포함하는 시스템 내 저장소
  • 인스턴스 : 데이터 개체를 구성하는 속성에 대한 데이터 타입과 값
  • 인덱스 : 정렬, 탐색을 위한 보조 도구
  • (3) SQL : 데이터베이스에 접근하도록 지원하는 국제 표준 언어
  • 1) 정의언어(DDL) : CREATE, ALTER, DROP
  • 2) 조작언어(DML) : SELECT, INSERT, DELETE, UPDATE
  • 3) 제어언어(DCL) : GRANT, REVOKE

COMMIT, ROLLBACK 등의 명령어를 포함한 TCL까지도 포함 가능

기업 내부 활용 데이터베이스

  • OLTP : 다량의 단기 거래를 실시간 처리
  • OLAP : 다차원 데이터를 대화식으로 분석
  • CRM : 고객과 관련 자료 분석하여 마케팅에 활용
  • SCM : 공급망 연결 최적화
  • ERP : 기업 경영 자원을 효율화
  • RTE : 최신 정보로 신속한 의사결정 지원
  • BI : 기업 보유 데이터 정리, 분석하는 리포트 중심 도구
  • BA : 통계 기반 비즈니스 통찰력
  • Block Chain : 네트워크에 참여한 모든 사용자가 정보를 분산, 저장
  • KMS : 기업의 모든 지식을 포함

빅데이터 출현 배경

  • 클라우드 컴퓨팅(온디맨드), 분산 처리 기술(하둡 기반), 비정형 데이터 확산, 디지털화, 인터넷 및 모바일 기기 보급, IoT 발달

빅데이터의 3V (가트너 정의)

  • (1) Volume(규모) : 데이터 양 증가
  • (2) Variety(다양성) : 데이터 유형 증가
  • (3) Velocity(속도) : 데이터 생성, 처리 속도 증가

그 외 5V/7V에 포함되는 요소

  • Value(가치) : 숨겨진 가치 발견이 중요
  • Veracity(신뢰성) : 고품질 데이터
  • Validity(정확성) : 데이터의 유효성 보장
  • Volatility(휘발성) : 데이터의 의미 있는 기간

5.빅데이터의 이해어려움부정형
1TB 짜리 데이터를 100MB/s 로 전송하는 상황에 관한 설명으로 옳지 않은 것은? (단, 1TB = 1,024GB, 1GB = 1,024MB)
정답 ③ — 1TB = 1,024 × 1,024 = 1,048,576MB 이고 1,048,576 ÷ 100 ≈ 10,486초 ≈ 2.9시간이다. 1TB 를 1,000MB 로 착각하면 10분이 나온다. 옮기는 데만 몇 시간이 걸리기 때문에 데이터가 있는 곳으로 연산을 보내는 분산 처리를 쓴다.근거 · 요약노트 밖 — 전송 시간 계산

데이터의 유형

  • 정량적 데이터 : 수치로 측정된 데이터 - 수치, 기호 (온도, 풍속)

점추정

점추정

  • 모집단이 특정한 값으로 추정하며, 추정량(Estimator)으로 모수를 추정

  • 1) 불편성(Unbiasedness) : 추정량의 기댓값이 실제 모수와 같음 (편향이 0이 되는 경우)
  • 2) 효율성(Efficiency) : 여러 추정량 중 분산이 작은 것이 더 효율적인 추정량
  • 3) 일치성(Consistency) : 표본 크기가 증가할수록 추정량이 모수에 가까워짐
  • 4) 충족성(Sufficiency) : 추정량이 모집단의 정보를 최대한 반영

‘불효일충’

  • (2) 대표적인 추정량
1) 모집단의 평균 μ → 표본평균 X̄ = 1n Σxi
2) 모집단의 분산 σ2 → 표본분산 S2 = 1n − 1 Σ(xi − X̄)2
3) 모집단의 비율 p → 표본비율 p̂ = X/n
  • (3) 평균제곱오차(MSE) : 점추정에서 추정량과 실제 모수 간의 평균적인 오차 크기

구간추정

  • (1) 모집단의 분산을 알고 있는 경우

  • 자유도가 n-1인 t분포를 이용하여 신뢰구간을 추정 g g

가설검정

  • (2) 대립가설(H1) : 귀무가설을 기각하는 가설, 증명하고자 하는 가설 (차이가 있다, 크다/작다)

  • 릿지회귀(L2 규제) : L2 규제항을 포함 λ Σβ2
