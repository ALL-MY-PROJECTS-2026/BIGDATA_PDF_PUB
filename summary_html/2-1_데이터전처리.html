    데이터 전처리

    원문 22~26쪽 (5쪽)

    원문 22쪽

    1. 데이터 정제

    데이터 정제

    데이터의 종류
    • (1) 척도 기준 구분
    • 1) 질적 척도
    • 명목척도 : 어느 집단에 속하는지 나타내는 자료 (대학교, 성별)
    • 순서척도(서열척도) : 서열관계가 존재하는 자료 (학년, 순위)
    • 2) 양적 척도
    • 등간척도(구간척도) : 구간 사이 간격이 의미가 있으며 덧셈과 뺄셈만 가능 (온도, 지수 등)
    • 비율척도 : 절대적 기준 0이 존재하고 사칙연산 가능, 가장 많이 수집되는 자료 (무게, 나이 등)
    • (2) 관측 기준 구분
    • 단변량 데이터 : 데이터의 특성이 하나인 데이터
    • 다변량 데이터 : 데이터의 특성이 두 개 이상인 데이터
    • 시계열 데이터 : 시간 순서에 따라 관측된 데이터 (=종단면적 데이터) * 종단면적 데이터(여러 시점에 측정) ↔ 횡단면적 데이터(한 시점에 측정) / 패널데이터(종단+횡단)
    데이터 정제
    • (1) 집계 : 데이터를 요약 (합계, 평균, 분산, 개수, 최대/최소)
    • (2) 일반화 : 데이터의 일반적인 특성 추출
    • (3) 정규화 : 데이터를 정해진 구간으로 조정하여 상대적 차이 제거
    • (4) 스무딩(=평활화) : 노이즈(잡음)을 제거하여 추세를 부드럽게 만듬

    데이터 결측값 처리

    결측값 종류
    • 존재하지 않는 데이터, null/NA로 표시
    • (1) 완전 무작위 결측(MCAR)
    • 다른 변수들과 아무런 상관없는 경우
    • 예) 입력 실수, 전산 오류
    • (2) 무작위 결측(MAR)
    • 특정 변수와 관련되어 발생하였지만, 결과와는 관계가 없는 경우
    • 예) 특정 정치 성향 유권자들의 응답률이 낮으나 정당의 득표율이 낮은 것은 아님
    • (3) 비 무작위 결측(MNAR)
    • 결측치가 변수의 결과에 상관이 있는 경우
    • 예) 소득이 낮은 응답자들의 응답률이 낮음
    원문 23쪽
    결측값 처리
    • (1) 단순대치법
    • 1) 완전분석법 : 결측값 가지는 데이터 삭제
    • 2) 평균 대치법
    • 비조건부 평균 대치법 : 단순 평균으로 대치
    • 조건부 평균 대치법 : 회귀분석의 결과로 대치
    • 3) 단순 확률 대치법 : 확률적으로 선택하여 대치
    • Hot-Deck : 현재 데이터 셋에서 비슷한 성향으로 대체
    • Cold-Deck : 유사한 외부 출처에서 비슷한 성향으로 대체
    • Nearest Neighbor : 바로 가까운 응답으로 대체
    • (2) 다중 대치법
    • 여러 번 대치하여 종합 (대치 → 분석 → 결합)

    다중 대치법은 분산 과소 추정 문제 해결이 가능

    데이터 이상값 처리

    이상값 처리
    • 극단적으로 크거나 작은 값이며, 의미 있는 데이터 일수도 있음 (키 220cm)
    • 이상값을 항상 제거하는 것은 아님
    • (1) ESD(Extreme Studentized Deviation)
    • 평균으로부터 표준편차의 3배 넘어가는 데이터는 이상값으로 판단
    • (2) 사분위수
    • Q1 – 1.5IQR보다 작거나, Q3 + 1.5IQR보다 크면 이상값으로 판단
    • 상한, 하한, 최솟값, 1~3사분위값, 최댓값 등을 표현하며, 평균값은 표현하지 않음
    • (3) Z-Score : 데이터를 정규화(평균 0, 표준편차 1) 후, 일정 임계 값 초과할 경우 이상값으로 판단
    • (4) DBScan : 밀도를 이용하여 밀도가 적은 부분의 데이터를 이상값으로 판단
    원문 24쪽

    1. 1. 척도에 대한 설명으로 옳지 않은 것은?

      정답 ③ — 등간척도(구간척도)는 구간 사이 간격에 의미가 있어 덧셈과 뺄셈만 가능하며 온도, 지수 등이 예다. 절대적 기준 0이 존재하고 사칙연산이 가능한 것은 비율척도다.

    2. 2. 결측값의 종류에 대한 설명으로 옳은 것은?

      정답 ② — MCAR은 다른 변수와 무관한 결측(입력 실수, 전산 오류), MAR은 특정 변수와 관련되나 결과와는 무관한 결측, MNAR은 결측치가 변수의 결과에 상관이 있는 경우(소득이 낮은 응답자의 낮은 응답률)다.

    3. 3. 결측값 처리 방법 중 단순 확률 대치법에 해당하지 않는 것은?

      정답 ④ — 완전분석법은 결측값을 가지는 데이터를 삭제하는 방법으로, 단순대치법 중 별도 항목이다. 단순 확률 대치법에는 Hot-Deck, Cold-Deck, Nearest Neighbor가 있다.

    4. 4. 다중 대치법의 절차와 장점으로 옳은 것은?

      정답 ① — 다중 대치법은 여러 번 대치하여 종합하며 대치 → 분석 → 결합 순으로 진행한다. 분산 과소 추정 문제 해결이 가능하다.

    5. 5. 이상값 판단 기법에 대한 설명으로 옳지 않은 것은?

      정답 ③ — 박스플롯은 상한, 하한, 최솟값, 1~3사분위값, 최댓값 등을 표현하며 평균값은 표현하지 않는다.

    2. 분석 변수 처리

    변수 선택

    변수 선택 방법
    • 분석 성능 향상을 위해 중요한 변수만 선별
    • (1) 필터(Filter) 방법 : 통계적 측정치를 활용하여 변수 선택
    • 기법 : 상관계수, 카이제곱 검정, F-검정, 상호정보량
    • 상관계수 매트릭스 분석
    • X1과 X4가 높은 상관계수를 가지므로, 둘 중 하나의 변수 제거

    상관계수는 -1 ~ 1사이의 값을 가지며, -1은 음의상관관계, 1은 양의상관관계를 의미

    • (2) 래퍼(Wrapper) 방법 : 모델의 성능을 기준으로 변수 선택
    • 기법 : 전진 선택법, 후진 제거법, 단계적 선택법
    • (3) 임베디드(Embedded) 방법 : 모델 학습 과정에서 변수 선택
    • 기법 : Lasso 규제, Ridge 규제

    차원축소

    차원 축소의 효과
    • 차원의 저주 해소, 데이터 시각화, 노이즈 제거, 데이터 압축, 성능 향상, 특징 추출, 계산 비용 절감

    차원의 저주 : 데이터 학습 시 차원이 높아질수록 알고리즘의 성능이 저하되는 현상

    차원 축소 기법
    • (1) 선형 차원 축소 기법
    • 1) 주성분 분석 (PCA)
    • 분산이 최대화되는 방향으로 차원을 축소
    • 2) LDA(Linear Discriminant Analysis)
    • 분류 에서 클래스 간 분산을 최대화하면서 차원을 축소하는 기법
    • 3) ICA(Independent Component Analysis)
    • 서로 독립적인 성분을 찾아 차원 축소
    • 4) SVD(Singular Value Decomposition)

    − m X n 크기의 비정방행렬 A를 행렬 분해 (A = U Σ VT)
    − U는 m x m 직교행렬, Σ는 m x n 대각행렬, VT는 n x n 직교행렬

    • 5) 요인분석(Factor Analysis)
    • 관측된 변수들을 몇 개의 잠재 요인으로 축소하는 방법
    • 심리학, 사회과학 등에서 잠재 변수의 해석이 필요한 경우
    원문 25쪽
    • (2) 비선형 차원 축소 기법
    • 1) MDS(Multi-Dimensional Scaling)
    • 데이터 간 거리정보의 근접성을 보존하는 차원 축소
    • Stress 함수의 값이 최소가 되도록 구성
    • 2) t-SNE (t-Distributed Stochastic Neighbor Embedding)
    • 고차원 데이터간 거리 정보를 확률적으로 유지하여 차원 축소
    • 데이터의 복잡한 비선형 패턴을 시각화 하며, 이미지나 텍스트 데이터에 적합
    • 3) UMAP(Uniform Manifold Approximation and Projection)
    • t-SNE와 유사한 비선형 차원 축소 기법으로, 구조적 패턴을 보존
    • 대규모 데이터에서 빠르게 적용 가능
    • 4) AutoEncoder
    • 신경망을 활용한 차원 축소 기법으로 데이터를 압축 후 다시 복원하는 학습

    파생변수 생성

    요약변수와 파생변수
    • (1) 요약변수 : 수집된 정보를 종합한 변수로서 재활용성이 높음 (1개월간 수입)
    • (2) 파생변수 : 의미를 부여한 변수, 논리적 타당성 필요 (고객구매등급)
    • 파생변수 생성방법 : 특징 추출, 결합, 부가적 정보 결합, 수학적 변환, 교호작용의 반영 * 교호작용 : 두 개 이상의 변수가 상호작용을 하여, 특정변수에 영향을 미치는 경우

    변수 변환

    수치형 변수 변환
    • (1) 표준화(Z-Score) : 평균 0, 표준편차 1로 변환 ~ N(0,1)
    Z = X − μσ
    • (2) 정규화(Min-Max Scaling) : 0에서 1사이로 변환
    Xnew = X − min(X)max(X) − min(X)
    • (3) 로그 변환 : 로그를 취한 값으로 변환, 데이터가 한쪽(좌측)으로 치우쳐 있을 시 활용
    Xnew = log X
    • (4) 그 외 변환 기법들

    지수변환, 제곱근 변환, Box-Cox 변환(양수 데이터의 비대칭 분포 시 활용)

    범주형 변수 변환
    • (1) 레이블 인코딩
    • 데이터를 정수로 변환, 서열 부여 문제 예) 오렌지, 바나나, 포도 → 0, 1, 2
    원문 26쪽
    • (2) 원-핫 인코딩
    • 고유 값에 해당하는 컬럼만 1로 표시하고 나머지는 0으로 표시
    • 많은 메모리 공간을 할당하지만, 각 범주간 독립적 예) 오렌지, 바나나, 포도 → [1, 0, 0], [0, 1, 0], [0, 0, 1]
    • (3) 타깃 인코딩

    타깃 변수를 평균값으로 변환

    불균형 데이터 처리

    불균형 데이터의 처리 방법
    • (1) 가중치 균형 적용(Weighted Balance)
    • 불균형 데이터에 가중치를 주는 방법
    • (2) 과소표집(UnderSampling)
    • 다수 데이터의 일부만 선택
    • 방법 : 랜덤 추출법, 계통 추출법, 집락 추출법, 층화 추출법
    • (3) 과대표집(OverSampling)
    • 소수 데이터를 복사하거나 유사한 데이터를 만드는 방식
    • 방법 : SMOTE, ADSYN, ROS

    1. 1. 변수 선택 방법과 기법의 연결이 옳지 않은 것은?

      정답 ④ — 모델의 성능을 기준으로 변수를 선택하는 것은 래퍼(Wrapper) 방법이다. 필터는 통계적 측정치를 활용한다.

    2. 2. 차원 축소 기법 중 선형 기법이 아닌 것은?

      정답 ④ — t-SNE는 비선형 차원 축소 기법이다. 선형 기법에는 PCA, LDA, ICA, SVD, 요인분석이 있다.

    3. 3. 요약변수와 파생변수에 대한 설명으로 옳은 것은?

      정답 ③ — 요약변수는 수집 정보를 종합하여 재활용성이 높고(1개월간 수입), 파생변수는 의미를 부여하여 논리적 타당성이 필요하다(고객구매등급). 교호작용은 두 개 이상의 변수가 상호작용하여 특정 변수에 영향을 미치는 경우다.

    4. 4. 범주형 변수 변환에 대한 설명으로 옳지 않은 것은?

      정답 ③ — 원-핫 인코딩은 많은 메모리 공간을 할당하지만 각 범주 간 독립적이라는 장점이 있다.

    5. 5. 불균형 데이터 처리 방법 중 과대표집(OverSampling)에 해당하는 것은?

      정답 ③ — 과대표집은 소수 데이터를 복사하거나 유사 데이터를 만드는 방식으로 SMOTE, ADSYN, ROS가 있다. 랜덤·계통·집락·층화 추출법은 과소표집(UnderSampling)의 방법이다.
