빅데이터의 가치

빅데이터 가치 산정이 어려운 이유

  • (2) 기존에 가치 없는 데이터도 새로운 분석기법으로 가치를 창조

빅데이터가 만들어내는 변화

  • (2) IT : 프로그래밍, 데이터 엔지니어링, 컴퓨팅 등
  • (3) 비즈니스 분석 : 커뮤니케이션, 스토리텔링, 시각화 등

데이터 사이언티스트의 필요역량

  • (1) Hard Skill : 이론적 지식(수학, 통계학, 가설검정 등), 분석 기술에 대한 숙련
  • (2) Soft Skill : 통찰력(창의적 사고, 호기심, 비판), 설득력(스토리텔링, 시각화), 협력(커뮤니케이션)

가트너가 제시한 역량 : 데이터 관리, 분석 모델링, 비즈니스 분석, 소프트 스킬

2.빅데이터의 이해보통부정형
빅데이터 분석 조직 구조에 관한 설명으로 적절하지 않은 것은?
정답 ④ — 집중 구조는 전담 조직이 전략 과제를 우선 수행할 수 있지만, 현업 부서의 자체 분석과 겹쳐 업무 중복 가능성이 단점이다. 나머지는 집중·기능·분산 구조의 정의 그대로다. (암기 : 집기분)근거 · 요약노트 7쪽
관련 요약 개념 · 요약노트 원문 7쪽

빅데이터 가치 패러다임 변화

  • Digitalization → Connection → Agency
  • (1) Digitalization : 아날로그 세상을 디지털로 전환
  • (2) Connection : 디지털화된 정보들의 연결
  • (3) Agency : 연결된 정보가 스스로 행동하는 주체

‘DigitalCA메라’

빅데이터 조직 및 인력

조직 및 인력방안 수립 (DSCoE : 분석조직)

  • 집중 구조 : 독립적인 전담 조직 구성 (중복 업무 가능성 존재)
  • 기능 구조 : 해당 부서에서 직접 분석 (DSCoE가 없음)
  • 분산 구조 : 분석 조직 인력을 현업 부서에 배치

2. 빅데이터 기술 및 제도

빅데이터 플랫폼

빅데이터 플랫폼

  • 데이터의 수집부터 저장, 처리, 분석 등의 파이프라인 전 과정을 통합적으로 제공하는 환경

빅데이터 플랫폼의 계층 구조

  • (1) 소프트웨어 계층
  • 데이터 수집 및 정제, 데이터 처리 및 분석, 사용자/서비스 관리
  • (2) 플랫폼 계층
  • 데이터 및 자원의 관리, 작업 스케줄링, 프로파일링
  • (3) 인프라스트럭처 계층
  • 자원의 배치 및 관리, 저장장치 및 네트워크 관리

소프트웨어가 상위 계층, 인프라스트럭처가 하위 계층

빅데이터 플랫폼의 범위에 따른 구분

  • 1) 광의의 분석 플랫폼 : 분석 서비스 제공엔진, 분석 어플리케이션, 분석 서비스 API, 하드웨어
  • 2) 협의의 분석 플랫폼 : 데이터 처리 프레임워크, 분석엔진, 분석 라이브러리

광의의 분석 플랫폼은 협의의 분석 플랫폼 요소들을 포함하는 개념

5.빅데이터의 이해보통사례적용
매출 데이터를 지역·기간·상품 축으로 바꿔 가며 대화식으로 집계·분석하는 시스템으로 가장 적절한 것은?
정답 ② — OLAP(Online Analytical Processing)은 다차원 데이터를 대화식으로 분석한다. OLTP 는 다량의 단기 거래를 실시간 처리하고, CRM 은 고객 자료를 분석해 마케팅에 활용하며, ERP 는 기업 경영 자원을 효율화한다.근거 · 요약노트 5쪽
관련 요약 개념 · 요약노트 원문 5쪽

데이터베이스 시스템

  • (1) DBMS : DB를 관리, 접근 환경 제공하는 소프트웨어
  • (2) 데이터베이스 스키마 : DB의 구조와 제약조건에 관한 전반적 명세
  • 메타데이터 : 데이터를 설명하는 데이터, 데이터 구조를 설명하고 검색하는데 활용
  • 데이터 사전 : 메타데이터와 데이터 구조 정보를 포함하는 시스템 내 저장소
  • 인스턴스 : 데이터 개체를 구성하는 속성에 대한 데이터 타입과 값
  • 인덱스 : 정렬, 탐색을 위한 보조 도구
  • (3) SQL : 데이터베이스에 접근하도록 지원하는 국제 표준 언어
  • 1) 정의언어(DDL) : CREATE, ALTER, DROP
  • 2) 조작언어(DML) : SELECT, INSERT, DELETE, UPDATE
  • 3) 제어언어(DCL) : GRANT, REVOKE

COMMIT, ROLLBACK 등의 명령어를 포함한 TCL까지도 포함 가능

기업 내부 활용 데이터베이스

  • OLTP : 다량의 단기 거래를 실시간 처리
  • OLAP : 다차원 데이터를 대화식으로 분석
  • CRM : 고객과 관련 자료 분석하여 마케팅에 활용
  • SCM : 공급망 연결 최적화
  • ERP : 기업 경영 자원을 효율화
  • RTE : 최신 정보로 신속한 의사결정 지원
  • BI : 기업 보유 데이터 정리, 분석하는 리포트 중심 도구
  • BA : 통계 기반 비즈니스 통찰력
  • Block Chain : 네트워크에 참여한 모든 사용자가 정보를 분산, 저장

  • 반정형 데이터 : 데이터를 설명하는 메타데이터를 포함 (HTML, XML, JSON, RDF)
  • 비정형 데이터 : 구조화되지 않은 자유로운 형태 (SNS, 유튜브, 음원)

  • 정량적 데이터 : 수치로 측정된 데이터 - 수치, 기호 (온도, 풍속)
  • 정성적 데이터 : 자료의 특징을 풀어 설명 - 언어, 문자 (기상특보, 주관식 설문 응답)

  • 수치형 : 연속형(키, 온도), 이산형(고객 수, 판매 건수)
  • 범주형 : 명목형(성별, 혈액형), 순서형(학점, 만족도 등급)
  • (4) 가역성에 따른 분류
  • 가역 데이터 : 원본으로 일정 수준 복원 가능
  • 비가역 데이터 : 원본으로 복원이 불가능
  • (5) 발생 위치에 따른 분류
  • 내부 데이터 : 운영, 비즈니스 활동, 고객 상호작용 등에서 발생하는 조직 내부에서 생성된 데이터

2. 분석 변수 처리

변수 선택

변수 선택 방법

  • 분석 성능 향상을 위해 중요한 변수만 선별
  • (1) 필터(Filter) 방법 : 통계적 측정치를 활용하여 변수 선택
  • 기법 : 상관계수, 카이제곱 검정, F-검정, 상호정보량
  • 상관계수 매트릭스 분석
  • X1과 X4가 높은 상관계수를 가지므로, 둘 중 하나의 변수 제거

상관계수는 -1 ~ 1사이의 값을 가지며, -1은 음의상관관계, 1은 양의상관관계를 의미

  • (2) 래퍼(Wrapper) 방법 : 모델의 성능을 기준으로 변수 선택
  • 기법 : 전진 선택법, 후진 제거법, 단계적 선택법
  • (3) 임베디드(Embedded) 방법 : 모델 학습 과정에서 변수 선택
  • 기법 : Lasso 규제, Ridge 규제

차원축소

차원 축소의 효과

  • 차원의 저주 해소, 데이터 시각화, 노이즈 제거, 데이터 압축, 성능 향상, 특징 추출, 계산 비용 절감

차원의 저주 : 데이터 학습 시 차원이 높아질수록 알고리즘의 성능이 저하되는 현상

차원 축소 기법

  • (1) 선형 차원 축소 기법
  • 1) 주성분 분석 (PCA)
  • 분산이 최대화되는 방향으로 차원을 축소
  • 2) LDA(Linear Discriminant Analysis)
  • 분류 에서 클래스 간 분산을 최대화하면서 차원을 축소하는 기법
  • 3) ICA(Independent Component Analysis)
  • 서로 독립적인 성분을 찾아 차원 축소
  • 4) SVD(Singular Value Decomposition)

− m X n 크기의 비정방행렬 A를 행렬 분해 (A = U Σ VT)
− U는 m x m 직교행렬, Σ는 m x n 대각행렬, VT는 n x n 직교행렬

  • 5) 요인분석(Factor Analysis)
  • 관측된 변수들을 몇 개의 잠재 요인으로 축소하는 방법
  • 심리학, 사회과학 등에서 잠재 변수의 해석이 필요한 경우
  • (2) 비선형 차원 축소 기법
  • 1) MDS(Multi-Dimensional Scaling)
  • 데이터 간 거리정보의 근접성을 보존하는 차원 축소
  • Stress 함수의 값이 최소가 되도록 구성
  • 2) t-SNE (t-Distributed Stochastic Neighbor Embedding)
  • 고차원 데이터간 거리 정보를 확률적으로 유지하여 차원 축소
  • 데이터의 복잡한 비선형 패턴을 시각화 하며, 이미지나 텍스트 데이터에 적합
  • 3) UMAP(Uniform Manifold Approximation and Projection)
  • t-SNE와 유사한 비선형 차원 축소 기법으로, 구조적 패턴을 보존
  • 대규모 데이터에서 빠르게 적용 가능
  • 4) AutoEncoder
  • 신경망을 활용한 차원 축소 기법으로 데이터를 압축 후 다시 복원하는 학습

파생변수 생성

요약변수와 파생변수

  • (1) 요약변수 : 수집된 정보를 종합한 변수로서 재활용성이 높음 (1개월간 수입)
  • (2) 파생변수 : 의미를 부여한 변수, 논리적 타당성 필요 (고객구매등급)
  • 파생변수 생성방법 : 특징 추출, 결합, 부가적 정보 결합, 수학적 변환, 교호작용의 반영 * 교호작용 : 두 개 이상의 변수가 상호작용을 하여, 특정변수에 영향을 미치는 경우

변수 변환

수치형 변수 변환

  • (1) 표준화(Z-Score) : 평균 0, 표준편차 1로 변환 ~ N(0,1)
Z = X − μσ
  • (2) 정규화(Min-Max Scaling) : 0에서 1사이로 변환
Xnew = X − min(X)max(X) − min(X)
  • (3) 로그 변환 : 로그를 취한 값으로 변환, 데이터가 한쪽(좌측)으로 치우쳐 있을 시 활용
Xnew = log X
  • (4) 그 외 변환 기법들

지수변환, 제곱근 변환, Box-Cox 변환(양수 데이터의 비대칭 분포 시 활용)

  • (2) 스피어만 상관분석 : 서열 척도, 순서형 변수, 선형/비선형적 관계 나타냄

(기) 피어슨 계수 = +1 / 스피어만 계수 = +1 (나) 피어슨 계수 = +0.8 / 스피어만 계수 = +1 (다) 피어슨 계수 = -1 / 스피어만 계수 = -1 (라) 피어슨 계수 = -0.8 / 스피어만 계수 = -1

스피어만 계수는 X와 Y가 선형 관계가 아니더라도 +1혹은 -1이 될 수 있다.

N(A∩B)전체 = P(A ∩ B)

  • (3) 히트맵 : 변수 간 상관관계를 색상으로 시각화

분포 시각화

  • (1) 원형 차트 : 원의 전체 크기를 100%로 하고, 파이 조각은 특정 범주가 차지하는 비율
  • 범주가 많아지면 시각적 해석이 어려움
  • (2) 모자이크 차트 / 트리맵 : 데이터의 비율과 계층구조를 시각적으로 표현
  • 음수 값을 표현하고 어렵고, 이웃하지 않은 사각형 사이 비교가 어려움

분석 목적에 따라 원형 차트, 모자이크 차트, 트리맵은 관계 또는 비율 시각화로 구분

비교 시각화

  • (1) 버터플라이 차트 : 두 개의 그룹을 좌우 대칭으로 비교
  • (2) 스타차트 : 3개 이상의 변수의 균형과 경향을 직관적으로 비교 가능
  • (3) 체르노프 페이스 : 사람의 얼굴 형태로 변환하여 시각적으로 표현
  • (4) 평행 좌표 그래프 : 다차원 데이터에 대한 시각화
